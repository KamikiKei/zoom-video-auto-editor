# Zoom動画 自動編集パイプライン

人間がやる作業じゃないやつを、ffmpeg 1発でやる仕組み。

## 自分のPCで使う（一番かんたん）
- **Windows**: `start_windows.bat` をダブルクリック
- **Mac**: `start.command` をダブルクリック（初回は右クリック→開く）
- ブラウザで画面が開くので、動画とサムネをドロップして使う
- 初回だけ Python と ffmpeg が必要。入っていない場合はランチャーが
  入れ方（コマンド）を表示するので、その通りにすればOK
- 終わったら黒い画面（ターミナル）を閉じる

## みんなで使う（Web画面・おすすめ）
```bash
pip install -r requirements.txt   # numpy / scipy (話者分離用)
python3 app.py                    # http://localhost:8765 を開く
```
- 画面の流れ: ①動画とサムネをドロップ → ②「話者を解析」で運営/登壇者を
  色分け表示、試聴サンプルで登壇者を選ぶと交代地点が開始タイムに自動入力
  → ③開始/終了は再生位置ボタンでも手動調整可 → ④編集してダウンロード
- 同じWi-Fi/LANの人は `http://<起動したPCのIP>:8765` でそのまま使える
  （アカウント不要・インストール不要、ブラウザだけ）
- 注意: LAN公開は信頼できるネットワーク内だけ。パスワード保護は未実装。

## サーバーに上げる場合
Dockerfile 同梱済み。Fly.io / Render / VPS など Docker が動く先なら
そのままデプロイできる。**その場合はホスティング先のアカウント作成が
必要になる**（無料枠のある Fly.io / Render 等）。大きなZoom動画を
扱うので、無料枠のディスク/メモリ上限には注意。

## 話者分離だけ使う
```bash
python3 diarize.py input.mp4 -o segments.json --samples-dir samples/
```
話者ごとの区間・試聴サンプル・「登壇者への交代」開始候補を出す。
声質が近い人同士は混ざることがあるので、最終判断は試聴で人が行う前提。
Zoomの参加者別音声ファイルや字幕(VTT)が手元にある場合はそちらが確実。

## やること
1. 本編の頭 (OP) とお尻 (ED) をカット
2. 頭とお尻に Canvaサムネイル画像を静止画クリップとして付ける
3. つなぎ目すべてにディゾルブ（映像 `xfade` / 音声 `acrossfade`）
4. mp4 (H.264 + AAC, faststart) で書き出し

サムネは本編の解像度・fpsに自動で合わせる。音声なし動画でも無音でつなぐ。

## 使い方（1本）
```bash
cd ~/workspace/video-auto-editor
python3 edit.py 元動画.mp4 サムネ.png -o 完成.mp4 \
  --trim-start 12 \
  --trim-tail 8 \
  --intro-sec 3 --outro-sec 3 --dissolve 0.8
```
- `--trim-start` : 頭から何秒カットするか（OP）
- `--trim-tail`  : 末尾から何秒カットするか（ED）
- `--end 00:42:10` のように終了位置の直接指定も可（trim-tailより優先）
- `--intro-sec / --outro-sec` : サムネを表示する秒数
- `--dissolve` : ディゾルブの長さ（秒）

## 使い方（まとめて・毎回同じ設定ならこっち）
1. `input/` に動画 mp4 を全部入れる
2. Canvaから書き出したサムネを `input/thumb.png` という名前で置く
3. `config.json` を作る（`config.example.json` をコピーして数値を変える）
4. 実行:
```bash
python3 edit.py --batch --config config.json
```
→ `output/元名_edited.mp4` ができる

## 設定ファイル (config.json)
```json
{
  "trim_start": 12,
  "trim_tail": 8,
  "intro_sec": 3,
  "outro_sec": 3,
  "dissolve": 0.8,
  "thumb": "input/thumb.png",
  "input_dir": "input",
  "output_dir": "output",
  "crf": 18,
  "preset": "medium"
}
```
画質: crf 18 = ほぼ劣化なし寄り。ファイルサイズ優先なら 20〜23。

## テスト済み
ダミー動画 12秒（頭2秒・尻2秒カット、サムネ頭尻各2秒、ディゾルブ0.5秒）
→ 出力 11.0秒ちょうど（2+8+2−0.5×2）。つなぎ目のフレームで
サムネと本編が半透明に重なっていることを目視確認済み。
テスト素材は `test/` にある（`test/out_edited.mp4`）。

## Zoom文字起こし (.vtt) 対応

Zoomのクラウド録画からダウンロードできる文字起こしファイル (.vtt) を
ステップ2で一緒にドロップすると、音声解析の代わりに文字起こしを使います。

- 話者名ラベル付きなので、運営/登壇者を名前で正確に分けられます
- 運営の「ご紹介します」等の紹介発言の直後に話し始めた人を、登壇者候補として自動で選びます
- 文字起こしがない場合は、従来どおり音声から話者を解析します (sherpa-onnx / 簡易版)
