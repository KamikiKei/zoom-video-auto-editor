# Zoom動画 かんたん自動編集

Zoomアーカイブ動画をアップロードすると、OP/EDカット + Canvaサムネを頭とお尻に挿入 + ディゾルブ適用をしたmp4を書き出します。
話者分離で運営/登壇者を色分けし、登壇者に代わる地点をトリミング開始に提案します。

ソースコード: https://github.com/KamikiKei/zoom-video-auto-editor
