# 現状分析（ドラフト）— 松尾研 講義コミュニティ 動画編集

目的：ツール選定（自作 / Vrew / ハイブリッド等）の判断材料と、DXの効果測定のベースラインを作る。
ステータス：判明している事実を先に埋めた。空欄はヒアリングで埋める。

## 業務フロー（本人確認済み、2026-11-21）

1. 収録（Zoom）
2. 運営から動画編集の依頼が石川さんに来る ← 入口が個人宛になっている
3. レコーディングをダウンロード
4. OP/EDをCanvaからダウンロード
5. OP/EDカット（開始点・終了点のカット）
6. もたりカット（無音・間のカット）
7. OP/EDをくっつける
8. ディゾルブを入れる
9. エクスポート
10. YouTubeに上げる
11. 概要欄を入れる

### 工程ごとの方針（本人の意向：判断が必要なところだけ人間を残す）

| 工程 | 方針 |
|---|---|
| 収録 | Zoom側（前提） |
| 編集依頼の受付 | 入口。**依頼はSlackで来る**（本人確認済み）。Slackをトリガーにパイプラインを回す設計にする |
| レコーディングDL | 自動（Zoom API） |
| OP/EDのCanva DL | 実態：**毎回Canvaから取り直しており、素材は回ごとに変わる**（本人確認済み）。マスター化では消せない。「対象回の素材はどれか」を特定する判断が発生する |
| カット / もたりカット / 接続 / ディゾルブ / エクスポート | 自動（現行ツール） |
| YouTubeアップロード | 自動（非公開） |
| 概要欄 | 実態：**connpassのイベントページから取ってきている**。自動化：対象回のconnpassページから取得して生成する |
| 公開 | **人間が残る**（最終確認。決定済み） |
| 例外（判定が怪しい回など） | **人間が残る**（判断） |

- 対象は松尾研 講義コミュニティのセミナー録画。「ペーパーアンド博」（Paper & Hacks）は160回を超える継続運営
- スコープ（2026-11-21 本人回答）：まず Paper & Hacks を解決するのが当面の対象。ただし他の基本的なイベントの編集にも広げたい意向あり
  → 判断への影響：シリーズが増えると「月の総本数」と「フォーマットの共通性」が効いてくる。ツール選定では拡張性も観点に入る
- 動画の長さは約1時間37分（実測した回）
- Zoomの文字起こしは話者ラベルがアカウント名と紐づいている
- 編集仕様は固定フォーマット：開始点カット、OP/ED＋ディゾルブ、無音カット＋つなぎ目ディゾルブ
- 現状の編集担当は石川さん（ツールも彼のPCで稼働）

## 課題（分析結果）

- **本人の目的（2026-11-21）**：この編集は定常作業であり、「効率化」や「分散」ではなく **仕事そのものをなくしたい**
- 現ツールの正確な評価：手作業（40分/本）は消えたが、「石川さんのPCで・石川さんが実行し・石川さんが保守する仕事」としては残っている。つまり仕事は消えていない
- **属人化の逆転**：手作業時代は動画チーム4人で回せたのに、ツール化で「ツールを使える人」が1人に減った
- 副次：前後工程（ダウンロード、アップロード）が手作業。ただし滞留はなくリードタイムも通常範囲なので優先度は低い
- 効果測定のベースライン：Before は月160分。金額・時間の規模は小さいので、選定の主軸は削減量ではなく「人の定常作業として消えるかどうか」になる

## この分析で埋めるべき判断材料

- 月の総編集時間（本数 × 1本あたり時間）→ ツール選定の時間軸
- 担当者の持続可能性 → 人の軸
- 許容できる月額コスト → 金の軸
